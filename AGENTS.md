# Olympiad Scoring App Rules

This is a Google Apps Script + Google Sheets scoring application used in a public school environment.

## Architecture

- Backend is Google Apps Script.
- Data storage is Google Sheets.
- clasp is used for GAS syncing.
- Preserve Apps Script compatibility.

## Privacy Rules

- Do not add external databases.
- Do not add analytics or tracking.
- Do not add Firebase or Supabase.
- Do not store student data outside Google Workspace.

## Coding Rules

- Preserve existing backend function names unless explicitly instructed.
- Prefer mobile-first responsive UI.
- Prefer incremental edits over rewrites.
- Keep files readable for teacher maintenance.
- Use Tabler icons where appropriate.
